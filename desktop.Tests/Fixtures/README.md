# EPUB test fixtures

Tests create small EPUB 2 and EPUB 3 packages in the system temporary directory.
The packages are generated by `EpubPackageServiceTests.CreateFixtureAsync` and
contain synthetic metadata, XHTML, CSS, and placeholder image bytes. They are
not copied from third-party books; the fixture-generation code is part of this
GPL-3.0-or-later project.

Use the fixture builder for normal and deliberately malformed packages so each
test can state its expected findings. Do not add a real user's book. Any
third-party sample must include its source and redistribution license here
before it is added to the test suite.
